## UI verbessern

```
Meine HTML-Seite sieht gerade so aus (Code):
[HTML CODE]

Verbessere das Design so:
- Moderner look (Karten statt flache Liste)
- Schönere Farben (nutze eine einheitliche Farbpalette)
- Auf einem Laptop-Bildschirm gut lesbar
Gib mir den kompletten veränderten HTML-Code.
```

## README schreiben

```
Hilf mir ein README.md für mein Projekt zu schreiben.

Mein Projekt: [PROJEKTNAME]
Was es macht: [BESCHREIBUNG]
Wie man es startet: [SCHRITTE]
Beispiel-Fragen: [3 BEISPIELE]

```

## Präsentation vorbereiten

```
Ich soll mein Projekt in 3-5 Minuten vorstellen.
Mein Projekt: [BESCHREIBUNG]
Besondere Features: [FEATURES]

Hilf mir eine kurze Präsentationsstruktur zu machen:
1. Was ich in einem Satz sage
2. Was ich bei der Demo zeige (in welcher Reihenfolge)
3. Wie ich die KI-Funktion erkläre
Maximal 5 Stichpunkte pro Abschnitt.
```
