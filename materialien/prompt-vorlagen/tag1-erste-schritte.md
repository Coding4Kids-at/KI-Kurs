# Prompt-Vorlagen — Tag 1: Erste Schritte

Fertige Prompts für den ersten Tag. Kinder können sie direkt kopieren und ausprobieren.

---

## Kontext-Experimente

```
Was ist 2+2?
```

```
Du bist ein Clown bei einem Kindergeburtstag. Was ist 2+2?
```

```
Du erklärst einem 5-jährigen Kind zum ersten Mal Mathematik. Was ist 2+2?
```

```
Du bist ein Mathematik-Professor an der Universität. Was ist 2+2?
```

---

## KI-Verständnis testen

```
Erkläre mir in 3 Sätzen wie du funktionierst.
```

```
Was ist der Unterschied zwischen dir und einer Google-Suche?
```

```
Hast du Gefühle?
```

```
Weißt du was heute passiert ist? (Heute ist der [DATUM])
```
