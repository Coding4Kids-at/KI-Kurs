# Schleifen (Loops) zum Anschauen

Drei fertige Seiten zum Thema Schleife — das wichtigste Grundmuster beim Programmieren.
Einfach im Browser öffnen (Doppelklick), sie laufen offline und kosten nichts.

| Datei | Was sie zeigt |
|-------|---------------|
| `sterne.html` | Eine Schleife wiederholt dieselbe Anweisung — 1 Zeile Code, hunderte Sterne. Regler für die Anzahl. |
| `animation.html` | Der Game-Loop: eine Schleife, die ~60x pro Sekunde läuft (bewegen → zeichnen → wieder von vorn). |
| `zahlenraten.html` | Der Computer errät deine Zahl (1–100) in höchstens 7 Versuchen — Schleife + Halbieren = Algorithmus. |

## Idee

Erst **anschauen und verstehen**, dann mit der Gemini-CLI **eine Sache ändern** (Anzahl, Farben,
Geschwindigkeit). Das ist billig (kaum Tokens) und trotzdem echtes Programmieren mit KI.
`zahlenraten.html` ist die Brücke zu Tag 4 (binäre Suche).

## Für Trainer

Reines Offline-JS, kein Netz/Key/`npm`. Wird als `schleifen/` mit dem CLI-Bundle ausgeliefert.
