Coding4Kids · KI im Griff

Vom leeren Laptop zur eigenen KI-Werkstatt

Diese Anleitung bringt einen Laptop, auf dem noch nichts läuft, Schritt für Schritt zum Workshop. Am Ende hast du deine eigene KI-Lab-App offen — und kannst loslegen.

🖥️ Windows 11 ⏱️ Setup ~15 Min 🧩 Vorwissen keins
➜ So liest du das: Jeder graue Kasten ist ein Befehl. Klick Kopieren, füg ihn ins Terminal ein (Rechtsklick = Einfügen), drück Enter. Der grüne Kasten sagt, was du sehen solltest.
Phase 0

Werkzeuge prüfen & nur Fehlendes installieren

Meist nur einmal nötig. Auf den Workshop-Laptops ist oft schon alles da — deshalb zuerst prüfen.

  1. Terminal öffnen

    Windows-Taste, PowerShell tippen, Enter. Das Fenster ist dein Terminal.

  2. Prüfen, was schon da ist
    PowerShell
    docker --version
node --version
    ✓Kommt eine Versionsnummer? Dann ist das Programm da — den Installations-Schritt überspringen.
    ✕Steht dort „not recognized"? Dann fehlt es — unten nachinstallieren.
  3. Docker Desktop nur falls oben gefehlt

    Öffne docker.com → Docker Desktop, installieren, PC neu starten. Dann Docker Desktop öffnen und warten, bis links unten der Wal grün ist.

    ⚠Der Wal muss laufen. Kommt später „Cannot connect to the Docker daemon", ist Docker einfach nicht offen.
  4. Node.js nur falls oben gefehlt

    Öffne nodejs.org, große grüne Taste (Version 24+), installieren, Terminal neu öffnen. (Brauchst du ab Tag 3 für deine eigenen Projekte.)

Phase 1

Die KI-Lab-App holen & starten

Die App ist dein Cockpit: Aufgaben, KI-Chat, Prompt Lab, Token-Visualizer und Fehler-Log. Sie kommt als fertiger Container — nichts zu bauen.

  1. App-Paket holen
    PowerShell
    docker pull ghcr.io/intsanerarity/ki-lab:latest
    ✓Am Ende Status: Downloaded newer image… (oder Image is up to date).
  2. App starten (mit Trainer-Key)

    Der Trainer gibt dir den API-Key — trag ihn statt KEY-VOM-TRAINER ein:

    PowerShell
    docker run -d -p 3000:3000 --name ki-lab -e GEMINI_API_KEY=KEY-VOM-TRAINER ghcr.io/intsanerarity/ki-lab:latest
    ✓Du siehst eine lange Container-ID — sonst nichts. Genau richtig, die App läuft im Hintergrund.
  3. Cockpit öffnen
    Browser-Adresszeile
    http://localhost:3000
    ✓Geschafft: Die KI-Lab-App fragt nach deinem Namen und zeigt die 5 Tage.
  4. Später wieder starten nur bei Bedarf

    Nach einem Neustart nicht nochmal docker run (Name schon vergeben), sondern:

    PowerShell
    docker start ki-lab
    ✓Dein Fortschritt bleibt erhalten. Danach wieder http://localhost:3000.
Phase 2

Der Durchlauf — die 5 Tage

Die genauen Aufgaben stehen in der App. Hier nur der rote Faden.

  • Tag 1

    KI verstehen

    Was ist ein LLM? Tokens, Kontext und warum die KI „das Nächste vorhersagt". Erste Fragen im KI-Chat.

  • Tag 2

    KI hinterfragen

    Halluzinationen, Bias und Rechenfehler aufspüren — und im Fehler-Log dokumentieren. KI ist nicht immer richtig.

  • Tag 3

    Mit KI bauen

    Prompt Lab, System-Prompts, eine eigene HTML-Seite mit der KI als Co-Pilot — und die Gemini-CLI im Terminal.

  • Tag 4

    Daten & APIs

    Echte Daten aus dem Netz holen, eine eigene Mini-API bauen und die Gemini-API ins eigene Projekt einbinden.

  • Tag 5

    Finale

    Dein eigenes KI-Projekt fertigstellen, README schreiben, der Gruppe vorstellen.

➜In der App: Tag wählen, Aufgabe lesen, ausprobieren, Antwort eintragen, abhaken. Der KI-Chat hilft dir jederzeit weiter.
Phase 3

Am Ende

Wenn du fertig bist — damit nichts im Hintergrund weiterläuft.

  1. App stoppen
    PowerShell
    docker stop ki-lab

    Dein Fortschritt bleibt gespeichert — beim nächsten Mal docker start ki-lab.

Hilfe

Falls es hakt

✕„Cannot connect to the Docker daemon" — Docker Desktop ist nicht offen. Starten, Wal abwarten.
✕localhost:3000 zeigt nichts — läuft der Container? docker ps; wenn ki-lab fehlt: docker start ki-lab.
✕Chat sagt „Trainer fragen" — der Key wurde beim Start nicht übergeben. docker rm -f ki-lab und mit korrektem -e GEMINI_API_KEY=… neu starten.
✕„name /ki-lab is already in use" — App läuft schon. Nicht neu runen, sondern docker start ki-lab.
Wenn du bis hier gekommen bist, schaffst du auch den Rest. Viel Spaß mit der KI. 🤖
