## Block 1 — Prompting ist ein Skill (10 min)

**An die Tafel:**
```
Schlechter Prompt:    "Erkläre KI"
Besser:               "Erkläre mir wie ein LLM funktioniert"
Gut:                  "Erkläre mir wie ein LLM funktioniert.
                       Ich bin 14 Jahre alt. Nutze Alltagsbeispiele.
                       Maximal 5 Sätze."
```

**Analogie:** Stell dir vor du gibst einem Koch nur "Essen machen" als Auftrag.
Er macht dir ein 3-Gänge-Menü aber du wolltest eigentlich ein schnelles Sandwich.
→ Je genauer die Anweisung, desto nützlicher das Ergebnis.

**Die 5 Elemente eines guten Prompts:**
```
1. ROLLE     "Du bist ein ..."
2. AUFGABE   "Mache / Erkläre / Schreibe ..."
3. KONTEXT   "Ich bin ... / Das Ziel ist ..."
4. FORMAT    "Antworte in ... Punkten / als Liste / in 2 Sätzen"
5. LIMIT     "Maximal ... Wörter / Keine Fachbegriffe"
```

Nicht alle 5 müssen immer dabei sein — aber je mehr, desto besser (meistens).

---

## Block 2 — System-Prompts (8 min)

**An die Tafel:**
```
Ohne System-Prompt: Generalist
Mit System-Prompt:  Spezialist

System-Prompt = permanente Anweisungen die immer aktiv sind
```

Beispiel:
```
System-Prompt: "Du bist Mario, ein freundlicher Pizzabote.
                Du kennst dich nur mit Pasta, Pizza und Italien aus.
                Antworte immer auf Italienisch."

User: "Was ist die Hauptstadt von Frankreich?"
KI:  "Mamma mia, so una cosa difficile... 
      Ich kenne mich leider nur mit Pizza aus!"
```

→ So baut man spezialisierte KI-Assistenten.

---

## Block 3 — KI als Coding-Partner (12 min)

**Neue Art zu programmieren:**
```
Alt:  Syntax auswendig lernen → Code schreiben
Neu:  Aufgabe beschreiben → KI schreibt Code → verstehen + anpassen
```

**Was ihr heute macht:**
1. KI schreibt euch eine HTML-Seite
2. Ihr öffnet sie im Browser
3. Ihr sagt der KI was ihr ändern wollt
4. KI ändert den Code
5. Ihr lernt dabei was der Code macht

**Das ist kein Schummeln — das ist der neue Standard.**
Profis nutzen KI als Coding-Assistenten.
Aber: Man muss den Code verstehen um zu beurteilen ob er korrekt ist.
